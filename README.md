# VIDYA-MITRA

Vidya Mitra is a dynamic MVP that combines:

- a learner-facing frontend,
- a Flask backend API,
- and saved ML models for adaptive recommendations.

## Run

```powershell
python -m pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.

## Dynamic MVP features

- learner form with real user inputs
- subject-aware topic dropdowns
- live learner snapshot while typing
- model-backed recommendation output
- unique game variant for the same learning outcome
- recent recommendation history in the browser
